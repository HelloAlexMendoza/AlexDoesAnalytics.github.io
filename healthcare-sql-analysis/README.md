# Healthcare Data Analysis — SQL

## Project Overview

This project uses SQL to explore a healthcare dataset and answer practical analytical questions about patients, medical conditions, admissions, billing, insurance providers, medications, doctors, and test results.

The goal of the project is to demonstrate how SQL can be used to summarize data, identify patterns, and support business-style analysis.

## Questions Explored

The analysis answers questions such as:

- How many unique patients are in the dataset?
- What are the most common medical conditions?
- What is the average patient age?
- How are patients distributed by gender?
- Which insurance providers account for the highest billing totals?
- What admission types occur most frequently?
- Which patients have abnormal test results?
- Which medications are most commonly associated with medical conditions?
- Which doctors appear most frequently by medical condition?
- What are the most prescribed medications?

## SQL Skills Demonstrated

- `SELECT`
- `WHERE`
- `DISTINCT`
- `COUNT()`
- `AVG()`
- `SUM()`
- `GROUP BY`
- `ORDER BY`
- `TOP`
- `IS NOT NULL`

This project demonstrates foundational SQL skills used in entry-level data analysis, including filtering records, calculating summary statistics, grouping data, ranking results, and turning raw records into useful analytical summaries.
