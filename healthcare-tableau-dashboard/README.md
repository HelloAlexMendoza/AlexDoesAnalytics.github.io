# Healthcare Data Tableau Dashboard

## Project Overview

This project uses Tableau to explore healthcare data and present key trends in a clear, interactive dashboard. The goal was to turn raw healthcare information into a visual format that makes patterns easier to identify and communicate.

## What I Analyzed

The dashboard focuses on healthcare-related trends and summary information, including patient and financial data, with the goal of supporting clearer data-driven interpretation.

## Skills Demonstrated

- Tableau dashboard development
- Data visualization
- Exploratory analysis
- KPI and summary reporting
- Communicating trends through visual design

## Project Value

This project demonstrates my ability to move beyond raw tables and create an interactive reporting experience that helps users quickly understand important patterns in a dataset.
